夹爪捏麻将：Xense 夹爪与视触觉凝胶垫

此前用 Allegro 手复现过 Taccel 的图 1（两指捏起刻“中”字的麻将牌，凝胶垫的形变图里读出字形）。这次换成一台真实型号的平行夹爪： Xense 夹爪按厂商 URDF 装配，两根手指的感测窗上各贴一块有限元凝胶垫。夹爪合拢、按凝胶垫自己测到的接触力把抓握力稳定在 10 N，把麻将牌提起 40 mm、停住、放回、松开； 贴着刻字面的那块凝胶垫读出“中”字。夹爪、凝胶垫、麻将牌和桌面都在 StiffGIPC 的同一个 Newton 求解里耦合，接触是 IPC。 用公开发布的 stiff-physics 0.8.5.5 wheel 加下面的复现包即可复现，不需要改引擎。

目录 结果视频一、场景二、复现三、用到的引擎功能四、结果五、限制

一、场景

夹爪朝下，两指沿世界 z 方向开合；麻将牌（20 × 26 × 12 mm，正面凹刻 0.9 mm 深、13 mm 大的“中”字）竖立在桌上，刻字面朝左指。

物体模型来源
手部组合件刚体（ABD）：法兰转接件 + T 形安装板 + 夹爪本体 + 腕部 D435i 外壳，0.83 kg厂商 URDF xense_gripper_with_mount_camera.urdf 的正运动学；质量、质心、惯量取 URDF 的 <inertial>
左右手指刚体，各 0.07 kg，经平移关节接在手部组合件上URDF 的 slider_left / slider_right，两个关节给同一个合拢量，等价于 URDF 里的 mimic
升降固定锚点 → 手部组合件的竖直平移关节代替机械臂，把夹爪提起、放下
凝胶垫 ×2有限元：24.0 × 16.0 × 2.5 mm，6064 个顶点、24929 个四面体，E = 0.2 MPa，ν = 0.4，摩擦 1.0；背面钉在手指的感测窗上感测窗是 Xense 手指内侧那块 16.6 × 28.4 mm 的平面（从 STL 量出）
麻将牌自由刚体，15 g，与凝胶垫的摩擦系数 0.8程序生成的刻字网格（与 Allegro 版相同）

时间线（dt = 5 ms，共 5.1 s）：

  1. 0–0.2 s：静置。
  2. 0.2–0.9 s：以 5 mm/s 合拢，碰到之后转为力控，把两块垫的平均法向力稳定在设定值。
  3. 0.9–1.3 s：夹紧。
  4. 1.3–2.5 s：以 40 mm/s 提起 40 mm。
  5. 2.5–3.1 s：停住。
  6. 3.1–4.3 s：放回。
  7. 4.3–5.1 s：松开。

触觉图像按 Taccel 的相机模型从凝胶垫顶点算出：

  • 深度：表面的正交高度场，像素 0.079375 mm，302 × 202 像素。
  • 形变图：深度减去未接触时的深度。
  • RGB：Taccel 公开的法向 → 颜色网络。
  • 7 × 7 个标记点。

二、复现

下载：xense_mahjong_repro.zip（9.5 MB） （release 页）。包里有：

  • 脚本；
  • Xense 夹爪的 URDF 包（URDF、STL、清单、校验和）；
  • 已经算好的简化碰撞网格、凝胶垫四面体网格和刻字麻将牌；
  • 触觉传感层的源码。

脚本也可以直接在网页上看：

  • xense_mahjong.py：场景、关节、力控和记录。
  • xense_assets.py：URDF 正运动学、感测窗测量、简化网格、凝胶垫和麻将牌。
  • render_xense_mahjong.py：触觉图像、字形评分和视频。

环境：

  • Linux x86-64，NVIDIA GPU（sm_80 / sm_89 / sm_120），Python 3.11 或 3.12。
  • stiff-physics 0.8.5.5 的 wheel，以及系统库 sudo apt install liburdfdom-dev。
  • pip install numpy scipy trimesh。
  • 只有生成触觉图像和视频时才需要：torch、pyrender、ffmpeg，以及 Taccel 仓库里的 taccel/data（n2rgb.pth、6k_ref.png，MIT 许可）。
pip install stiff_physics-0.8.5.5-cp311-cp311-linux_x86_64.whl numpy scipy trimesh
unzip xense_mahjong_repro.zip && cd xense_mahjong_repro
# 仿真：一张 A800 上约 14 分钟
python examples/xense_mahjong/xense_mahjong.py --out out/f10 --grip-force 10
# 触觉图像、字形评分和视频
PYOPENGL_PLATFORM=egl python examples/xense_mahjong/render_xense_mahjong.py out/f10/xense_mahjong.npz \
    --taccel-data /path/to/Taccel/taccel/data

可选参数：

  • --char 發：换一张牌，需要 CJK 字体和 tetgen 重新生成资产。
  • --grip-force：抓握力设定，单位 N；URDF 里的 effort 是 20 N。
  • --gel-E：凝胶模量，单位 Pa。
  • --mu：凝胶与牌的摩擦系数。

输出：

  • xense_mahjong.npz：每帧的刚体位姿、两块垫的顶点、法向力和关节行程。
  • readout.png / readout.json：字形评分和空白对照。
  • xense_mahjong.mp4：视频。

本页的结果就是用公开 wheel 和这个复现包跑出来的，与开发版引擎的结果逐帧一致（第四节）。

三、用到的引擎功能

这个例子没有改引擎。它用到的引擎功能都已在 0.8.5.5 的 wheel 里：

功能接口在这里的用途
从顶点和面直接建刚体load_mesh_from_data(..., body_type="ABD")手部组合件、两根手指、麻将牌、锚点
按给定值设置质量与惯量set_abd_body_inertia、set_abd_body_density夹爪用 URDF 的 <inertial>，麻将牌用密度
程序化平移关节 + 位置伺服add_prismatic_joint、set_prismatic_target、get_prismatic_current_distance两指开合（同一合拢量 = mimic）和升降
有限元凝胶垫钉在刚体上add_fem_pin_to_abd（触觉层的 GelBody.add_pinned）凝胶垫背面跟随手指
逐顶点接触力（牛顿）get_vertex_contact_forces(False, "total")每块垫的法向力，是力控的反馈
绝对接触距离Config(absolute_dhat=1e-4)0.1 mm 的接触层，比 0.9 mm 的刻字深度小得多
碰撞排除add_collision_exclusion、add_ground_collision_skip凝胶垫不和自己的手指、手部组合件、另一块垫碰撞

触觉传感层（stiff_physics.sensors，纯 Python，从 Taccel 移植）还不在 0.8.5.5 的 wheel 里，复现包把它放在 examples/xense_mahjong/_vendor/sensors。如果已安装的 stiff-physics 没有这个模块，例子会自动改用随包的这一份。它包括：

  • 凝胶垫资产（四面体网格、背面和感测面顶点、标记点）；
  • 把凝胶垫加进引擎的 GelBody；
  • 深度相机、形变和标记点位移；
  • RGB 网络的封装。

搭这个场景时遇到两个坑，记在这里：

  • 质量不能从不封闭的网格算。为了碰撞检测快，夹爪用了简化网格（夹爪本体原 STL 有 24.9 万个三角形），简化后不封闭。引擎从它算出的体积和惯量没有意义： 在 0.8.5.5 里第一步能量就是 NaN，所有物体不动；开发版里给它们 set_abd_body_mass 会让整个求解卡住（每步 2 s，什么都不动）。 改用 URDF 给的质量、质心和惯量（set_abd_body_inertia）后两个版本都正常，结果一致。
  • 凝胶垫整面压住时很硬。Taccel 默认的 0.5 MPa 凝胶垫被整面压住时约 200 N/mm（薄层受约束），10 N 只压进约 0.05 mm； 第一版力控（增益 2e-5 m/N）因此在 7 N 和 17 N 之间来回跳。改用视触觉硅胶常见的 0.2 MPa、增益 3e-6 m/N、接近速度 5 mm/s 后，力稳定在设定值 ±0.1 N。

两组都用公开 wheel 跑出（10 N 839 s，15 N 1379 s）。抓得更紧，凝胶压得更深，但字形读出几乎不变：笔画处的凝胶也被压下去一些，阈值随之上移。核对：同一个复现包分别用公开的 0.8.5.5 wheel 和开发版引擎各跑一次（10 N），1020 步里所有刚体和凝胶垫顶点的位置相差不超过 0.002 mm，垫的法向力相差不超过 0.15 N；用时分别是 839 s 和 859 s（一张 A800）。

五、限制

  • 凝胶垫加在手指感测窗那块突出 2 mm 的平面上；厂商 STL 里没有单独的凝胶，这块平面本身没有去掉。凝胶模量取 0.2 MPa 是视触觉硅胶的常见范围，不是 Xense 传感器的实测值。
  • RGB 触觉图用的是 Taccel 公开的网络和参考图（缩放到这块垫 302 × 202 的分辨率），是 Taccel 那款传感器的外观模型，没有按 Xense 传感器标定；形变图和标记点位移不依赖它。
  • 图像按“面对刻字面的人看到的方向”显示；真实相机在凝胶背后，看到的是镜像。
  • 漏读的约 30% 集中在笔画边缘：感测面的三角网格约 0.5 mm，深度图又做了 1 像素的平滑，比 1.3 mm 宽的笔画细节粗。
  • 夹爪没有接在机械臂上，升降由一个竖直平移关节代替。URDF 的 45 mm 行程在约 42.4 mm 处两指就会相撞，关节限位不能代替接触。
