SAFE 触觉闭环抓取：原理与实现

"SAFE" 是商用夹爪 SDK 三种控制模式（POSITION 位控 / SPEED 速控 / SAFE）中"结合触觉传感器的安全控制模式"的名字； "闭环"指控制回路经过传感器绕回来。这一页解释它解决什么问题、回路怎么转、我们在 StiffGIPC 里的完整实现细节， 以及为什么这条演示具有证明力而不是"演出来的"。

一、它解决的问题：夹多大力，事先算不出来

抓一个物体需要的最小夹持力由摩擦定律决定：F_grip ≥ m·g / (2μ)。 但重量 m 和摩擦系数 μ 在抓之前都是未知的——物体可能比看上去重，表面可能有油。开环控制只有两种失败方式：

  • 夹轻了：摩擦力扛不住重量，物体在指间下滑、脱落；
  • 夹重了：捏碎鸡蛋、捏瘪纸杯——没有触觉的夹爪只能"宁可信其重"，一律用大力。

人手的解法是抓取神经科学的经典结论（Johansson & Westling 的提物实验）： 先用刚好的小力捏住，皮肤一旦感到微滑，握力反射性地加一档。SAFE 模式就是把这个反射搬到夹爪上。

二、闭环回路

① 触觉读数 — 两块指面 pad 输出法向夹持力 Fn 与滑移信号（pad 与物体的相对位移增量）
↓
② 控制器决策 — 力伺服把 Fn 拉向设定值；检测到滑移则把设定值上调一档（封顶 fmax）
↓
③ 关节执行 — 闭合关节的位置目标向内推进一小步
↓
④ 物理世界 — 法向力增大 → 摩擦容量 μ·Fn 增大 → 滑移变慢、停止
↺ 回到 ①（每个物理帧循环一次）

回路收敛的终点是"刚好夹得住"的最小力：既不掉，也不捏坏。这正是触觉传感器存在的核心理由——没有它，夹爪对指尖发生的一切是盲的。

三、我们的机械实现：三关节棱柱链

演示里的夹爪没有任何预排轨迹，每个运动部件都是引擎里的自由刚体（ABD），由棱柱关节约束和驱动：

anchor（Fixed，安装点）
  │  垂直棱柱关节（提升轴，axis = +y）
carriage（自由刚体，横梁）
  │  水平棱柱关节 ×2（闭合轴，axis = ∓z，每 jaw 一个）
jawL / jawR（自由刚体）
  ~  stitch 弹簧（软缝合，Config.soft_motion_rate = 1e4）
FEM 凝胶 pad ×2（触觉膜，3 mm，E = 1 MPa）
  • 棱柱关节约束除滑动轴外的全部相对自由度；实测该链在重力下零下垂（吊架/双 jaw 竖直漂移 < 0.001 mm）；
  • pad 通过 stitch 弹簧挂在 jaw 上——这是本仿真栈唯一验证过的"凝胶跟随载体"驱动方式（硬钉接会把求解器磨死）；
  • 驱动接口：每帧对每个关节写 set_prismatic_target / set_prismatic_strength（未配置的关节会跑默认驱动态，所以每个关节每帧必写）。

四、控制律（tactile_gripper.ParallelGripper，逐条）

POSITION：带 fmax 力钳位的位控

step = clip(cmd_opening − opening, ±vmax·dt)     # 目标限速推进
if F_meas > fmax and step 朝闭合方向: step = 0    # 力到上限即停（零蠕变实测）

SAFE：力伺服 + 滑移触发的再夹持

F_meas = max(pad 法向力)                          # 力读数来自 pad 本身（见下文）
step   = clip(k_i·(F_set − F_meas), −0.35, +0.12) mm/帧   # 位置增量∝力误差 = 对力的积分控制
if F_meas < 0.3 N: step = max(step, 0.10 mm)      # 未接触时粗进给

slip  += Δ(pad 高度) − Δ(物体高度)                 # 只在双侧接触时累计
if slip > 0.25 mm:                                # 滑移事件
    F_set = min(F_set × 1.6, fmax); slip = 0      # 设定值阶梯上调，封顶
为什么力读数用 pad 而不用关节？ 引擎的 get_prismatic_drive_force 把原始 strength 当刚度用，少读约 1/dt² 倍 （实测 pad 承力 186 N 时它只读 0.005 N，真实伺服刚度 ≈ strength/dt² ≈ 1.3×10⁶ N/m）。 我们改用 pad 的触觉法向力做 fmax 钳位与状态读出——这也正是"夹爪内建触觉传感器"这个产品形态的本意。

五、演示为什么有证明力

关键在初始条件是照着"必然失败"设计的：初始设定 1.5 N/pad，摩擦对系数 μ = 0.6， 摩擦容量 = 2 × 0.6 × 1.5 = 1.8 N < 螺栓重量 2.75 N——滑移是摩擦定律的必然，不是编排。随后发生的一切都是回路自己找到的：

阶段观测说明
提升开始pad 在升、螺栓没跟上（螺纹压印逐牙下跳）滑移信号出现
提升 4–8 帧4 次滑移事件：设定值 1.5 → 2.4 → 3.8 → 6.1 → 9.8 N再夹持阶梯
之后全部帧滑移增量 ≈ ±0.000 mm，螺栓与吊架轨迹严格平行回路收敛
保持段双 pad 切向力之和 = −2.75 N = −mg牛顿静力学恒等式：悬挂全靠摩擦

最后一行是免费的物理判卷器：如果任何一环（接触力、摩擦、关节、缝合）算错，这个和不会正好等于负的物体重量。
