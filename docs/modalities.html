VBTS 贴装与原生压阻，到底怎么实现的

同一个 IPC 引擎上的两条独立触觉路线：VBTS 贴装是"给手指粘一块软凝胶膜 + 虚拟相机"， 输出连续高分辨率的触觉图像；原生压阻是"手指自己的表面就是传感器"，不加任何软体， 输出离散 taxel 阵列的电信号。两条路线共享同一个力学真值来源——IPC 求解器的逐顶点接触力。

一、VBTS 贴装：从一块 STL 到一台虚拟传感器

1. 凝胶制造（fabricate 管线）

# 以夹爪指面 pad（40×20×3 mm）为例
盒体 STL（表面预细分 1.5 mm）
  → tetgen 四面体化（max_volume = 2×10⁻¹⁰ m³ → 顶点间距 ≈0.55 mm，4967 顶点 / 22639 四面体）
  → 顶点掩码：coat_mask（z≈0 的感测面）｜ stick_mask（z≈3 mm 的安装面）
  → 标记点阵：每个 marker 记为（所在涂层三角形的 3 个顶点索引 + 重心坐标）
  → 相机配置：正交投影，0.079375 mm/px，分辨率按膜面尺寸取整（504×252）
  • 标记用重心坐标绑定的意义：marker 位置成为 FEM 状态的线性函数，膜怎么变形它就怎么走，无须任何跟踪算法；
  • 真实外壳同形版本：从厂商 STEP 用 gmsh 提取最大平面感测窗，按窗口尺寸走同一条管线（厂商 CAD 本体不入库）。

2. 接入引擎（GelBody，三种安装方式）

凝胶作为 FEM 软体加载（E = 1 MPa，ν = 0.4，ρ = 1000 kg/m³——软硅胶量级）， 安装面顶点与载体（手指/jaw 刚体）之间三选一：

方式机制力学性质结论
add_fixed安装面顶点世界固定传感器不动，物体来压压入台架用（SDK 验证场景）
add_pinned硬钉接到刚体（每步覆写位置）单向：载体感受不到凝胶反力，边界力无界抓取会把求解器磨死（实测 175 次线搜索失败），弃用
add_stitched安装面每顶点一根 stitch 弹簧拉向载体锚点（刚度 = soft_motion_rate = 10⁴）双向、有界：接触抵抗时凝胶滞后于载体而非被硬注入位移抓取一律用它（平移驱动精确）

摩擦按引擎约定成对相乘：μ_pair = μ_gel × μ_object（凝胶 1.0 × 螺栓 0.6 = 0.6，剪切实验实测滑移比 0.600±0.008）。

3. 传感器跟着手走（位姿账本）

  • 手上的安装帧来自对指求解与共设计（L20 的安装倾角从 24.7° 优化到 6.3°）；夹爪上是"平板 pad 约定"（涂层 z=0 面朝物体）；
  • 引擎陷阱：get_abd_body_transforms 返回的是"顶点均值质心 + 单位旋转"的规范帧，不是加载位姿。 当前传感器位姿必须用刚体运动复合：W = (C_now · C_load⁻¹) · T_load · M_mount——直接当位姿用会差约 8 mm，taxel 窗读全零（踩过）。

4. 观测管线（几何 → 图像）

FEM 顶点（世界系） → 旋入传感器局部系
  → 正交 z-buffer 光栅化涂层三角网 → 原始深度图
  → 高斯平滑（σ≈1–2 px，压掉网格三角化棱面）
  → 逐像素法向（对像素间距的度量梯度——原库的索引梯度会渲染出与接触无关的图像，已修）
  → normal→RGB 残差 MLP（预训练检查点）＋参考底图 → Rectify 触觉图像
标记点：重心插值出 3D 位置 → 正交投影 → Marker2D/3D/Flow

二、原生压阻：不加软体，表面即传感器

1. 接触体就是手指本身

  • L20 指尖的 distal 网格（去重后的 CAD 表面，~10⁴ 顶点）直接作为刚体（ABD）接触体加载——场景里没有任何附加凝胶；
  • 每根手指挂在沿按压方向的棱柱关节上做力伺服（taxel 法向和反馈给目标推进；刚-刚接触约 30 N/mm，开环位控会瞬间怼到 100 N 以上）；
  • 相邻指尖互碰会把彼此顶起 3–4 mm（真实手指靠各自伺服避开），故排除指-指碰撞、保留指-物接触。

2. 力 → taxel：分箱是精确的

IPC 逐顶点接触力 F_i（牛顿，精确）
  → 旋入传感器局部系，取压缩法向分量 F_z⁺ 与切向 (F_x, F_y)
  → 按静止局部坐标 (x, y) 落进 rows×cols 网格（如 8×6 @ 2 mm）
  → 每 taxel 力 = 落入顶点力之和
  • 物理依据：taxel 读数本来就是"其覆盖面上牵引力的积分"，逐顶点力分箱就是这个积分（横向顶点漂移 ~0.05 mm ≪ 2 mm 间距）；
  • 守恒自检每帧输出：taxel 总和 / 凝胶总法向力 ≈ 1.0；
  • 工程规则一：每 taxel 需 ≥10 个顶点平均（IPC 力集中在接触顶点上，太细的间距读数会抖）；
  • 工程规则二：taxel 网格中心对准指尖切点顶点——第一版对准"指腹窗口中点"，结果阵列带着 120 N 却读 0.0 N（窗口偏了 8 mm）。

3. 力 → 电信号（显式换能模型，参数可换）

电导  G = G₀ + k·F        # FSR 数据手册的"电导近似线性于力"，G₀=1/1MΩ，k=2×10⁻⁴ S/N
噪声  G += N(0, σ_G)       # 电导域高斯噪声
分压  v = V_ref · R_pull / (R_pull + 1/G)
量化  adc = round(v / V_ref · 4095)   # 12-bit；手套层再映射到 0–254

1–5 是清晰分层的：第 1–2 步（力的获取与分箱）是物理；第 3–5 步（换能与读出电路)是显式模型， 对着任何一款真实压阻片的数据手册换参数即可仿真那款产品——我们不假装电学部分是从第一性原理来的。

4. 手套层（把分区拼成整手）

  • 各指尖的 taxel 阵列作为"分区"放进 63×39 画布的文档化槽位（thumb/index/middle/ring/pinky/palm），画布其余格恒零——传感器只在真实存在的位置，画布对此诚实；
  • ADC 0–254 + 去皮（tare 捕获当前画布为零点偏置）+ 接触点统计（阈值、计数、和、最大、均值）；
  • IMU 从掌部刚体位姿序列有限差分：比力 f_b = Rᵀ(a − g) 与体角速度——捷联 IMU 的理想版。
