同场景对照：我们的粒子求积液体 vs 恢复版 Unified_GIPC

之前流固耦合演示页里的"液体龙砸方块塔"来自恢复版 Unified_GIPC 引擎，看起来比我们实验台尺度的水要好。 为了弄清差别到底来自方法还是来自工作点，我们把恢复版引擎（反编译后可运行的版本，GPU 内核与原版一致）和我们的 StiffGIPC 粒子求积液体（UG 模式）放进完全相同的场景——同样的几何、网格 5 mm、粒子间距 2.5 mm、时间步 5 ms、同一张显卡—— 跑五个标准测试，并排看。结论：两家在每一项上都是同一水平，连缺陷都一样；恢复版演示好看，是因为它的工作点是 16 cm 网格、每格约 4000 个粒子的大尺度飞溅，不是方法更好。 唯一它有而我们没有的二次 B 样条插值已经移植进我们的引擎，表现也一致。

一、并排视频（左：我们的引擎；右：恢复版）

每个视频的两边使用同一组初始粒子（同一随机种子）、同样的容器和参数。粒子按速度着色（深色静止，亮色快）。晃荡为 2.5 倍慢放。

注意：这一节里"我们的引擎"是 11-06 修复前的默认设置（节点严格收敛的牛顿）——晃荡和浮块视频里我们这边 3 s 后还在动、恢复版已静止，正是第六节分析的根因，不是时间不够长：默认设置下底层涡旋随时间增长。修复后的两种模式见下面两段四联视频和第七节。

三、根因（两家共有）

  1. 三线性粒子求积 = 六面体单元的数值积分。每格 1 个粒子是减缩积分，出现沙漏模式（静水塌缩）；每格 8 个以上是近不可压材料的完全积分，出现体积锁定：水偏硬，阻尼大、晃荡频率低、浮力偏大（每格 64 粒子时吃水反而只有 4.2 mm）。
  2. 二次 B 样条解除锁定（阻尼 ÷4、频率对、吃水对），但静水里出现壁面层不稳定：离壁 3 mm 内的伪速度是盒子中心的 3 倍，盒子越小体积损失越大（6 cm 盒 37%，12 cm 盒 28%）。张力、求解精度、节点质量下限、密度再锚定、PIC/APIC、每格 27/64 粒子都不能消除它。原因是光滑核的支撑伸进墙内的网格节点，只靠粒子-固体屏障挡不住；修法是我们主路径已有的网格级壁面约束。
  3. 密闭满水容器（无自由面）两种插值都让 Newton 每步撞迭代上限，水不动——粒子求积液体不适合密闭容器。

四、速度

同场景、同卡：我们的引擎每次 Newton 迭代约 13–30 ms，恢复版约 180–260 ms（快 7–17 倍）；每步快 1–9 倍（恢复版收敛阈值松、迭代少，不稳定时会自动拆子步）。 恢复版是反编译重建版，主机侧用 Python 组装稀疏矩阵，比原版 wheel 慢约 2.4 倍（用其自带的 case13 计时校准：原版 300 帧 635 s，重建版 1554 s）。扣掉这一项，我们的引擎比原版大约每次迭代快 3–7 倍。

五、对引擎的结论（11-06）

  • 恢复版的流固耦合方法（粒子代理 IPC 屏障 + 粒子求积 MPM）我们已经有，表现一致，没有可移植的优势。分区求积对流体从不触发；BDF2 二阶积分不降低阻尼。
  • 已移植的二次 B 样条（开关默认关）显著改善动态行为，但静水需要壁面约束配合。
  • 实验台尺度的演示（烧瓶、烧杯里的水要静止 30 秒）仍用主路径（网格级壁面约束 + 静水稳定项，静水残余速度 0.03 mm/s）。

六、"恢复版不加处理就能静止"的根因（11-07）

上面的并排视频里有一个两家唯一不一致的地方：静水和浮块场景中恢复版 1 s 后几乎静止，我们的粒子 3 s 后还在动，并且液面以约 0.15 mm/s 缓慢下降。我们把两家的每一步输出逐项对比，找到了根因，并且在两个方向上都复现了它。

  1. 现象不是"水在动"，而是粒子在格子内部聚团。最近邻距离统计（以粒子间距为单位）：我们的 p1 分位数 2 s 内从 0.46 降到 0.32，小于半间距的粒子对每秒增加 630 对且指数增长；而每个粒子追踪的体积比 J 完全不变（0.988 / 0.999 / 1.006）。恢复版的 p1 恒为 0.46。
  2. 模型层面：这是粒子求积能量的零空间。流体能量 Σ Vp ψ(Jp) 对每个格子只约束 8 个求积点的 J，格子 24 个节点自由度里剩下的剪切 / 沙漏模态零刚度；重力沿这些模态做功，真正的能量极小点就是粒子聚团、整柱缓慢压实，释放的势能变成底层涡旋（动能从 11 µJ 涨到 27 µJ）。对时间步、κ、dhat、BDF2、APIC、摩擦、网格对齐、PCG 精度全部不敏感。
  3. 公式逐项一致。恢复版的试探步、提交、P2G、预测子、流体能量 ½κ(Jacc·det(I+Σu⊗∇w)−1)²·V、梯度、解析特征系统投影的 Hessian（剪切模态 |p|/2、旋转模态 −p/2）和我们的内核一一对应。
  4. 差别在牛顿迭代深度。恢复版的停止规则是"粒子处插值的物理方向范数 < √scale2·newton_tol·dt ≈ 25 µm 就停，且最后一次方向不施加"，每步平均 2.9 次牛顿（实际施加约 2 次）；我们的规则是节点最大位移 < 1e-4·dt·包围盒 ≈ 1.5 µm，每步 12.5 次。截断的牛顿把解偏向初值（u = 0，静止），是数值阻尼而不是物理。
  5. 双向验证。我们把牛顿截断到 1.7 次/步：近对增长 +79/s、液面漂移 −0.06 mm/s（恢复版 +59/s、−0.04）；恢复版改成严格收敛（newton 1e-4、pcg 1e-8，14.1 次/步）：+537/s、−0.15 mm/s、p1 0.45→0.37——和我们默认版一模一样。

七、两种工作模式

根因清楚之后，引擎的修改有两件，都不改公式，组合成两种模式：

  1. 粒子判据的牛顿退出规则（LIQ_CONV_PARTICLE=1）：液体不再用节点位移、而用插值到粒子上的位移进入"最大位移 < 阈值"的退出判据——这正是恢复版"物理方向范数"所量的东西。零空间（沙漏）模态在节点上幅值大、在粒子上小 3–5 倍，于是牛顿在解完它们之前就停下，这些方向每步都留一截没解 = 隐式阻尼，而粒子可见的真实运动仍按阈值收敛。
  2. 显式亚格子密度控制（LIQ_UG_PUSH=0.95）：求解前把靠近到 0.95 倍播种间距以内的粒子推开（每步 ≤ 0.25 间距且 ≤ 0.45 dhat），补上粒子求积模型里没有的"逐点不可压"——它管体积守恒和聚团，不管涡旋。

走过的弯路也记在这里：节点沙漏粘性在任何能压住聚团的强度下都把晃荡和浮块冻住（沙漏模态承载的正是粒子求积的亚格子物理，半格加载就是一个沙漏模态）；隐式粒子对斥力能量能彻底压住聚团但代价失控（最软的变体 1 小时只算 0.3 s）；密度再锚定能止住液面漂移但对聚团无效；单独的 push 守住了体积和粒子分布，但底层涡旋反而更强。
