Engine · Liquids

实验台液体：把水放进 IPC 求解器

化学实验台演示需要能和薄玻璃器皿、凝胶指垫双向耦合的液体。我们把隐式 MPM Lite 直接放进 IPC 的 Newton 求解： 网格节点是未知量，粒子是 IPC 接触点，“水推玻璃、玻璃兜住水”在同一次求解里完成。随后的全量审计让完整五段演示快了 2.61 倍； 路径追踪视频里“静止的水面在动”，则追到了一个根因：固壁只作用在粒子上，没有作用在网格上。 修好根因后，又把残余的慢环流压住：静止的水从约 0.04 降到约 0.001 cm/s，长时间运行中水位也不再下沉。 10-19 起对液固耦合做全面复审：补上可追溯的计数器、用薄板分隔试验量化串扰与穿板、加入兼容性屏蔽、闭合支撑力预算，并开始把运动学滴管泵换成腔压模型。 10-22 起用最新的水（隐式表面张力、地面也是墙，桌上的水不冻结）重做了完整演示，并按公开实验逐项检查水像不像：倒水、装水、静水与真实一致，晃动和铺开明显偏黏。 阅读逐步改动日志 → · 复审改动清单 → · 像不像真水 →

Engine · MPM × IPC

流固耦合：液体龙、弹性龙与方块塔

MPM 粒子（液体或弹性体）和 IPC 布料、刚体放在同一个 Newton 求解里：网格节点是未知量，每个粒子是 IPC 的接触代理顶点， 接触的梯度和 Hessian 经插值权重链式回传到网格。两万粒子的液体龙落到钉边的布上，90 个刚体立方体叠成的塔压在布中央； 把龙换成橡胶（fixed-corotated 弹性材料）后，同一条管线跑出被压扁但体积不变的龙。四个场景各有 MP4 和时间采样的 USD。 阅读场景、方法、差异与下载 →

USD（Y 轴向上、米制、时间采样：刚体变换 + 布料顶点 + 粒子 Points）： 液体龙 · pygipc 版（90 MB） 液体龙 · 直写版（90 MB） 弹性龙（91 MB） 弹性方块（12 MB）
MPM 模块在引擎开发分支上，尚未进入公开发布的 wheel。

Coverage

覆盖度与诚实边界

已覆盖并可运行验证

  • OutputType 13/13，单引擎快照同帧供给；跨 GPU（4090/A800）数值一致
  • 生命周期 + 后处理模式：scan/create/release；runtime 导出 → 离线重放回归 p99 0.000 mm
  • 夹爪控制 SDK：POSITION/SPEED/SAFE + fmax 力钳位（零蠕变实测）
  • SAFE 触觉闭环：滑移检测自动增力，保持段 ΣFx = −mg
  • 压力手套：63×39 画布 / 分区 / ADC / IMU
  • 实时工作台：交互程序 + 无头录制
  • 真实外壳同形凝胶：WS/OS/GS 三款压印验证
  • selectSensorInfo / calibrateSensor 同语义
  • ForceResultant 六维合力/力矩，仅对感测涂层面积分（真实 pad 语义）
  • 数据采集：多模态天然同帧；4000 张数据集先例；LeRobotDataset v3.0 导出（官方 loader 验证）
  • 任意规格 pad 制造，可按目标传感器 CAD 换壳

未覆盖 / 不适用

  • Rectify 色彩为 Taccel GelSight 标定，非目标产品光学（几何忠实，色板是别家的）
  • 远程模式（EzROS/DDS 网络层）——仿真进程内无真实需求，未实现
  • N/A 硬件专属：序列号授权 / OTA / 柔性件拆装 / 转接法兰
